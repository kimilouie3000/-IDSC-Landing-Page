## How to use these documents
- Treat the PowerPoint's named pages and navigation as the baseline for the site's content structure.
- Treat Figma as the visual source of truth for the landing page.
- Replace placeholders with information approved by IDSC before publication.
- Label a feature as implemented only after it has been built and tested. These documents describe the intended site; they do not claim that features already exist in code.

## Important content note
The presentation includes the tagline **“Empowering Futures with Dedicated Service”**, the label **“IDSC Pulse”**, an announcements/advisories section, and contact details. Verify time-sensitive information such as fees, requirements, contact details, and office hours with the school before launch. Exact Figma design tokens must be read from the actual frame; they are not guessed in this documentation.
